# Focus Guard

A personal Android app that blocks distracting apps and websites for a focus time you choose. Once a session starts, it can't be stopped, edited, or switched off until the time runs out.

## Getting the app
Every time the code changes, GitHub builds the app automatically. Open **Releases** on this page and download `FocusGuard.apk` from the newest build.

## Installing
1. Open `FocusGuard.apk` on your phone and allow "Install unknown apps" for your browser or Files app when asked.
2. Open Focus Guard and tap **Open Accessibility settings**, then turn on **Focus Guard**.
3. If that switch is greyed out: tap **Open App info**, then ⋮ (top right), then **Allow restricted settings**, and try again.

## Using it
1. Type the websites to block, one per line (e.g. `youtube.com`).
2. Tick the apps to block.
3. Set the minutes and tap **Start focus**.

During focus, opening a blocked app or site sends you to a "Stay focused" screen. Focus Guard's own settings, its Accessibility switch, and its uninstall screen are also blocked until the time is up.
